# 냉로그 · 제출 시연 초안

## 한 문장

구매 기록에서 냉장고 재고를 만들고, 먼저 사용할 재료를 확인한 뒤 자연어로 소비를 기록하는 모바일 웹앱.

## 90초 시연

- 0–15초: 오늘 화면. “재료를 기록하는 것보다 계속 수량을 맞추는 일이 번거롭습니다. 냉로그는 구매부터 실제 소비까지 연결합니다.”
- 15–40초: 구매 추가에서 “애호박 5개” 입력, 결과 확인 후 등록. 이미지 경로를 보여줄 때는 “현재 이미지 분석은 예시 데이터입니다”라고 설명한다.
- 40–65초: 도우미에 “애호박 2개 썼어”. 대상과 변경량을 확인한 뒤 적용. 냉장고에서 3개 확인.
- 65–80초: 새로고침 후 3개 유지. 구매·소비 기록과 보관 변경 확인.
- 80–90초: “서버 저장과 검증을 먼저 완성했고, 실제 모델은 Provider 인터페이스에 연결할 준비가 되어 있습니다.”

## 구현 증거

- 방문자별 D1 저장, 수량과 원장을 함께 갱신, 동시 수정 충돌 및 재전송 중복 방지.
- AI 응답은 일반 코드로 검증하며 사용자가 확인한 뒤 변경한다.
- 현재 모의 분석/규칙 기반 브리핑임을 UI에 표시한다.
- 테스트 21개 및 실제 브라우저 흐름 검증. 상세 증거는 QA.md.

## 제출 전에 완료할 항목

- 정확한 대회 공고, 제출 형식, 심사 기준과 일정 확인. 현재 저장소만으로 특정 회차의 규정 충족을 선언하지 않는다.
- 공개 대상 승인 후 심사자가 접근 가능한 URL 확인.
- 식품 기간 정책 근거와 표시 문구 검토.
- 자동 브라우저 회귀 검사 및 저장 장애/충돌 화면 증거 보강.
- 실제 화면 녹화와 최종 소개 자료 작성. 현재 문서는 시연 초안이며 최종 제출본이 아니다.
