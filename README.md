# 냉로그

> AI로 기록하고 관리하는 냉장고

냉로그는 영수증이나 구매내역을 활용해 식재료 등록을 간편하게 하고, 냉장고 속 재료의 수량과 보관 상태, 사용 시점을 관리할 수 있도록 돕는 서비스입니다.

등록한 식재료를 냉장·냉동·실온으로 나누어 관리하고, 먼저 확인해야 할 재료를 쉽게 파악하며 남은 재료를 효율적으로 활용할 수 있도록 구성했습니다.

---

**기본값은 Mock이며 OpenAI 서버 어댑터를 구현했다.** 실제 키 입력과 유료 인식 검증은 아직 하지 않았다. Mock 이미지는 고정 예시, OpenAI 활성화 시 실제 이미지·문장을 서버에서 OpenAI로 전달한다. 설정과 비용 제한은 [AI_PROVIDER_SETUP.md](AI_PROVIDER_SETUP.md)를 따른다. 예상 사용 시점은 식품 안전 판단을 대신하지 않는다.

## 왜 냉로그인가요?


식재료를 사고도 냉장고에 무엇이 있는지 잊거나, 직접 하나씩 기록하는 과정이 번거로워 관리가 끊기는 경우가 많습니다.

또한 냉장, 냉동, 실온처럼 보관 방식에 따라 관리 기준이 달라지고, 남은 식재료가 있어도 무엇부터 사용해야 할지 판단하기 어려운 경우가 있습니다.

냉로그는 이러한 과정을

**구매 → 등록 → 보관 → 소비 → 활용**

하나의 흐름으로 연결해 냉장고 속 식재료를 더 쉽게 관리할 수 있도록 만들었습니다.

---

## 주요 기능

### 1. 간편한 식재료 등록

식재료를 직접 입력하거나 영수증 및 구매내역 이미지를 활용해 등록할 수 있습니다.

- 직접 식재료 등록
- 영수증 촬영 및 이미지 업로드
- 온라인 주문내역 및 구매내역 캡처 업로드
- 이미지 속 구매 품목 분석
- 식품 / 비식품 / 확인이 필요한 품목 구분
- 축약되거나 애매한 상품명의 식재료 후보 판단
- 분석 결과 확인 및 수정 후 냉장고 등록

AI가 분석한 결과를 바로 저장하지 않고, 사용자가 식재료 이름, 수량, 구매일, 보관 방식 등을 최종 확인한 뒤 등록하도록 구성했습니다.

---

### 2. 냉장고 식재료 관리

등록된 식재료를 한눈에 확인하고 관리할 수 있습니다.

- 전체 식재료 목록 확인
- 냉장 / 냉동 / 실온 보관별 분류
- 식재료 이름 및 수량 확인
- 구매일 및 등록 정보 확인
- 식재료 상세 정보 확인
- 수량 수정
- 소비 기록
- 폐기 기록
- 보관 방식 변경

식재료 상태가 변경될 때마다 기록을 남겨 현재 냉장고에 어떤 재료가 얼마나 남아 있는지 확인할 수 있습니다.

---

### 3. 사용 시점 및 D-Day 관리

식재료의 보관 방식과 등록 정보를 기준으로 먼저 확인해야 할 재료를 쉽게 파악할 수 있습니다.

- 식재료별 예상 사용 시점 표시
- D-Day 형태의 상태 확인
- 사용 시점이 가까운 식재료 우선 확인
- 사용 시점이 지난 재료 별도 표시
- 냉장 / 냉동 / 실온 보관 상태 반영

제품에 실제 소비기한 정보가 입력된 경우 해당 날짜를 우선 사용하고, 정보가 없는 경우에는 서비스의 관리 기준을 활용합니다.

> 냉로그의 예상 사용 시점은 식재료 관리를 돕기 위한 참고 정보이며 식품 안전을 보장하는 기준은 아닙니다.

---

### 4. 오늘의 냉장고 확인

홈 화면에서는 현재 냉장고 상태를 빠르게 확인할 수 있습니다.

- 전체 식재료 현황
- 냉장 / 냉동 / 실온 식재료 요약
- 먼저 확인해야 할 재료
- 가까운 D-Day 식재료
- 사용 시점이 지난 식재료
- 구매 추가 바로가기

냉장고를 열어보기 전에 어떤 재료부터 확인해야 하는지 쉽게 파악할 수 있도록 구성했습니다.

---

### 5. 자연어 빠른 기록

복잡한 메뉴를 찾지 않고 간단한 문장으로 냉장고 상태를 변경할 수 있습니다.

예를 들어,

`계란 3개 썼어`

`닭가슴살 냉동으로 옮겼어`

`우유 1개 버렸어`

와 같은 입력을 식재료 변경 명령으로 해석합니다.

실행 전 변경 대상과 수량을 다시 확인하며, 같은 이름의 식재료가 여러 개 존재하는 경우에는 사용자가 대상을 직접 선택하도록 합니다.

---

### 6. 남은 식재료 활용

냉장고에 남아 있는 식재료를 확인하고 현재 보유한 재료를 활용할 수 있도록 돕습니다.

AI 기능을 통해 냉장고에 등록된 식재료를 기반으로 활용 가능한 메뉴나 조리 아이디어를 제안합니다.

단순히 식재료를 기록하는 데서 끝나지 않고 실제 소비까지 이어지는 냉장고 관리 경험을 목표로 합니다.

## AI 활용

냉로그에서 AI는 사용자가 식재료를 더 쉽게 등록하고 관리할 수 있도록 돕는 역할을 합니다.

### 구매내역 분석

영수증 또는 온라인 구매내역에서 상품 정보를 분석해 냉장고에 등록할 식재료 후보를 생성합니다.

### 식품 여부 판단

구매내역에는 식품 외에도 생활용품이나 기타 상품이 함께 포함될 수 있기 때문에 식품과 비식품을 구분하고 필요한 항목만 냉장고 등록 후보로 제공합니다.

### 애매한 상품명 해석

영수증에는 상품명이 축약되거나 실제 식재료 이름과 다르게 표시되는 경우가 있습니다.

냉로그는 이러한 상품명을 그대로 저장하는 대신 상품 정보를 분석해 관리하기 적합한 식재료 이름을 제안합니다.

예시:

`하림 닭가슴살 블랙페퍼 100g 5팩 → 닭가슴살`

`서울우유 1L → 우유`

분석 결과가 확실하지 않은 경우에는 AI가 임의로 확정하지 않고 사용자에게 후보를 보여주거나 직접 입력하도록 합니다.

### 냉장고 재료 활용

현재 냉장고에 남아 있는 식재료를 기반으로 활용 가능한 메뉴나 조리 아이디어를 제안하는 기능에 AI를 활용합니다.

---

## 사용자 확인 중심 설계

냉로그는 AI의 판단을 자동으로 확정하지 않습니다.

다음과 같은 정보는 등록 전에 사용자가 직접 확인할 수 있습니다.

- 원본 상품명
- 최종 식재료 이름
- 수량
- 단위
- 구매일
- 보관 방식
- 소비기한 또는 관리 날짜

AI가 잘못 분석한 경우에도 사용자가 직접 수정할 수 있도록 하고, 확인이 필요한 품목이 남아 있을 경우에는 바로 등록되지 않도록 구성했습니다.

---

## 데이터 관리

냉로그는 식재료의 현재 상태뿐만 아니라 식재료가 어떻게 변경되었는지도 함께 관리합니다.

기록되는 주요 변경 사항은 다음과 같습니다.

- 구매 및 등록
- 소비
- 폐기
- 수량 조정
- 보관 방식 변경

수량이 변경되거나 식재료를 소비한 경우에도 기존 기록을 단순히 삭제하지 않고 변경 내역을 유지합니다.

## 실행 방법

Node.js와 npm을 사용합니다.

`npm install`

로컬 데이터베이스를 준비합니다.

`npm run db:migrate:local`

개발 서버를 실행합니다.

`npm run dev`

빌드 및 기본 검증은 다음 명령어로 실행할 수 있습니다.

`npm test`

`npm run typecheck`

`npm run lint`

`npm run build`

AI 기능을 사용하기 위해서는 별도의 API 환경변수 설정이 필요합니다.

민감한 API Key는 코드나 GitHub 저장소에 직접 작성하지 않고 서버 환경변수로 관리합니다.

## 프로젝트 방향

냉로그는 처음에는 단순한 식재료 소비기한 관리 앱으로 시작했지만, 현재는 식재료의 구매부터 등록, 보관, 소비까지 이어지는 전체 과정을 관리하는 서비스로 확장하고 있습니다.

특히 사용자가 매번 식재료를 직접 입력해야 하는 불편을 줄이기 위해 영수증과 구매내역을 활용한 AI 기반 등록 기능을 중심 기능 중 하나로 발전시키고 있습니다.

앞으로는 다음 기능을 지속적으로 개선할 예정입니다.

- 영수증 및 구매내역 인식 정확도 개선
- 애매한 상품명 분석 정확도 개선
- 냉장고 식재료 기반 메뉴 추천 고도화
- 식재료 관리 기준 개선
- 사용자 계정 및 기기 간 동기화
- 알림 기능
- 모바일 사용 경험 개선

## 프로젝트 목표

냉로그가 해결하려는 핵심 문제는 단순합니다.

**"내 냉장고에 무엇이 있는지 쉽게 기록하고, 잊지 않고 사용하는 것."**

AI는 냉로그의 목적 그 자체가 아니라, 식재료를 기록하고 관리하는 번거로운 과정을 줄이기 위한 도구로 활용합니다.
